# LocalMesh Design Exploration

## Three Possible Directions

### 1. Field Instrument
**Very Brief Intro:** A tactile network-operations workbench inspired by avionics panels and field radios. It should make distributed state feel inspectable, active, and reliable rather than abstract.

**Probability:** 0.07

### 2. Soft Constellation
**Very Brief Intro:** A light, editorial workspace where devices become points in a calm cartographic field. It would make collaboration feel human and unhurried.

**Probability:** 0.04

### 3. Relay Archive
**Very Brief Intro:** A document-led system ledger that emphasizes revision history, trust, and traceability through archival typography and slim technical annotations.

**Probability:** 0.09

---

# Chosen Direction: Field Instrument

## Design Movement
**Instrumental futurism** — informed by mission-control consoles, cartographic notation, and precise industrial product design. The interface is a working surface, not a marketing dashboard.

## Core Principles
1. **State is visible:** Connection, encryption, replication, and integrity are shown as legible, persistent signals.
2. **Topology is the canvas:** The network map is the organizing visual structure, with tools orbiting the active system state.
3. **Warmly technical:** Dense data is balanced by calm spacing, restrained color, and plain-language event summaries.
4. **Action has consequence:** Partitions, reconnections, and edits create immediate, traceable changes in the event stream.

## Color Philosophy
The base is midnight blue-black rather than neutral black, allowing the simulation to feel like a field environment at night. Bone-white text keeps technical detail readable. **Relay Green** is reserved for verified, synchronized truth; ochre highlights transitional or queued conditions; vermilion indicates an intentional partition. The accent colors communicate states rather than decorate panels.

## Layout Paradigm
An **asymmetric operations bench**: a slim left command rail, a large central topology field, and a right-hand document/activity inspector. This creates a purposeful visual flow from control, to network state, to the evidence of change.

## Signature Elements
1. A live topology field made of fine coordinate dots, softly pulsing connection paths, and device stations.
2. Signal chips with rounded-square geometry that encode encryption, sync phase, and integrity at a glance.
3. A compact monospaced event ledger with timestamp markers and trace-line motifs.

## Interaction Philosophy
The simulator responds like physical equipment: controls have crisp press feedback; a partition visibly breaks a link; reconnection sends motion across the topology; document edits produce clear queued/synced status. Hover exposes deeper state without hiding the primary story.

## Animation
Use short, purposeful animations only. Link paths transition over 180–240ms; replication particles travel on reconnect; event rows enter with a 40ms stagger; controls compress slightly on press. Respect reduced-motion preferences by replacing movement with color/state changes.

## Typography System
**Space Grotesk** anchors headings and navigation in a firm, modern grotesk. **IBM Plex Mono** is used for version vectors, network IDs, timestamps, and transport metadata. Hierarchy uses wide tracking for labels, deliberate weight contrasts, and no generic UI type defaults.

## Brand Essence
**LocalMesh is the observable collaboration layer for teams who cannot depend on a constant network.**

Personality: **resilient, legible, exacting**.

## Brand Voice
Headlines are concise and operational; CTAs name the real system action; microcopy explains state without jargon when possible.

Example lines:

> “Write now. Reconcile when the network returns.”

> “Partition applied — 2 peers are carrying divergent edits.”

## Wordmark & Logo
The mark is a **three-node relay loop**: three offset signal points joined by a continuous angular path, suggesting local replication that keeps moving even when a connection breaks. It must work as a single-color emblem without text.

## Signature Brand Color
**Relay Green — #C6F46F**. A high-visibility, optimistic verification signal used only for trusted, in-sync system states.
